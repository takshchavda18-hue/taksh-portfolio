# Taksh Chavda — Portfolio

A responsive, surreal 3D-inspired portfolio built with HTML, CSS, Bootstrap 5, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is needed for those assets. The layout and artwork are custom CSS.

## Deploy to Vercel
1. Extract the ZIP.
2. Upload the folder to a GitHub repository.
3. In Vercel, choose **Add New → Project**, import the repository, and deploy.
4. Framework preset: **Other**. Build command and output directory can be left blank/default for this static site.

You can also use Vercel CLI from this folder: `vercel`.

## Before publishing
- Replace `hello@example.com` in `index.html` with your real email address.
- Add real project names, descriptions, and links when you have projects to showcase.
- Verify all academic and skill details are accurate before submitting for evaluation.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, 3D CSS artwork, and animations
- `script.js` — dynamic hero text, pointer parallax, and navigation behavior
